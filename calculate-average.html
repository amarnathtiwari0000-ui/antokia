What Is an Average?

An average is a value that represents a group of numbers. In basic mathematics, the most commonly used average is the arithmetic mean.

To calculate the average, add all the numbers together and divide the total by the number of values.

Average Formula
Average = Sum of All Values ÷ Number of Values

Example of Average Calculation

Numbers
10, 20, 30, 40, 50
Sum
10 + 20 + 30 + 40 + 50 = 150
Number of Values
5
Average
150 ÷ 5 = 30

How to Calculate Average Manually

  1. Write down all the numbers.
  2. Add all the numbers together.
  3. Count how many numbers you have.
  4. Divide the total sum by the number of values.
  5. The result is the average.

Where Is Average Used?

  • Calculating average marks of students.
  • Finding average test scores.
  • Calculating average monthly expenses.
  • Comparing average prices.
  • Analysing numerical data.
