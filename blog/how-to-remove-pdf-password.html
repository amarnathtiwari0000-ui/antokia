How to Remove a PDF Password (When You Know It): 3 Free Ways

Tired of typing the password every time you open a bank statement or salary slip? Here is how to save an unlocked copy.

Updated: November 2026 · Antokia Guide

Bank statements, salary slips, Form 16 and insurance documents often come as password protected PDFs. The password is useful for security, but typing it every time is annoying, and some upload portals cannot accept a locked file at all. If you know the password, you can save an unlocked copy in a minute using tools you already have.

Important: These methods work only when you already know the password, or when the file has no open password. They do not break or guess passwords. Remove protection only from files that belong to you or that you are allowed to use.

Two Kinds of PDF Passwords

TypeWhat it doesCan you remove it?
Open password (user password)Asks for a password before the file opensYes, if you know the password
Permissions password (owner password)File opens, but printing, copying or editing is restrictedOften yes by saving a new copy, if you are allowed to use the file

Method 1: Print to PDF in Google Chrome (Free)

Step 1: Open the PDF in Chrome

Drag the file into a Chrome window, or right click and choose Open with Chrome. Enter the password when asked.

Step 2: Open the print dialog

Press Ctrl+P (Cmd+P on Mac).

Step 3: Choose Save as PDF

Set the destination to Save as PDF and click Save.

Step 4: Check the new file

The saved copy opens without a password. Open it once to confirm that all pages are there.

Method 2: Adobe Acrobat

If you have Acrobat Pro, open the file with the password, go to File, then Properties, then Security, and change the Security Method to No Security. Save the file. The free Acrobat Reader cannot do this.

Method 3: On Your Phone

On Android, open the PDF in Chrome or Google Drive, enter the password, then use Print and Save as PDF. On iPhone, open the file in Files, enter the password, use Share, then Print, and pinch out on the preview to save a new PDF.

Tip: Bank PDFs often use a password made from your details, such as the first letters of your name plus your date of birth. Check the email or the bank instructions that came with the file.

What If I Forgot the Password?

There is no safe free shortcut. Ask the sender to share the file again, download a fresh copy from the bank or company portal, or contact their support. Be careful with websites that promise to crack any PDF, because they may keep your private document.

After Unlocking: Useful Next Steps

  • Too big for a form? Use Compress PDF to reduce the size.
  • Need only a few pages? Use Extract PDF Pages or Remove PDF Pages.
  • Want to combine documents? Use Merge PDF.
  • Need to edit the text? Try PDF to Word.

Common Mistakes

  • Trying to unlock a file you are not allowed to use.
  • Uploading a private bank statement to unknown websites.
  • Deleting the original before checking that the unlocked copy has every page.
  • Leaving unlocked copies of sensitive files in shared folders or on shared computers.
